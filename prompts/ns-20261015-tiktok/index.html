📋 Copy the Prompt

Hyper-detailed miniature world diorama video: [WORLD_TYPE: glowing night city / underwater coral reef / enchanted forest / cozy tiny kitchen / tiny desert oasis]. Macro photography style, extreme detail on every tiny element, slow cinematic camera orbit, subtle ambient motion (flickering lights, flowing water, rising steam), vibrant saturated colors, magical lighting. Loop the motion seamlessly so the ending matches the beginning — a perfect natural loop. Vertical 9:16, [DURATION: 8-12 seconds]. No text on screen.

🚀 How to Use This Prompt

  1. Generate 4-6 diorama stills in Midjourney/Flux (vary [WORLD_TYPE] per video; keep the same macro style).
  2. Animate each still in Kling / Veo 3 image-to-video with 'seamless loop, gentle continuous motion' — ending frame must match the start.
  3. Layer ASMR ambience in CapCut (rain / water / fireplace sounds); hook = the tiniest surprising detail in second 1 (a tiny person waves); caption trick = comment-bait question like 'Which tiny world would YOU live in?' — comments push the video onto the FYP.

💡 Pro Tips

  • Start with the ASMR sound inside second 1 — no intro frame, the sound IS the hook.
  • Keep loops seamless so TikTok compounds watch time on every replay.
