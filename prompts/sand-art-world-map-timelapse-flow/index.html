Sand Art World Map Timelapse — Google Flow Prompt for Satisfying Facebook Reels

🚀 How to Use This Prompt

  1. Open Google Flow and start a new 9:16 vertical video generation.
  2. Paste the prompt above exactly as written into the prompt box.
  3. Generate 3-4 variations and keep the one where the world map shape is most recognizable.
  4. Add soft ASMR sand audio in editing — the sound is half the satisfaction.
  5. Post as part of a sand-art series (maps, animals, portraits) so viewers follow for the next pour.

💡 Pro Tips

  • The reveal matters: hold the finished map for a full 2 seconds before the sweep so viewers screenshot it.
  • Satisfying art reels earn huge saves — end with a clean finished image, never a messy wipe.
