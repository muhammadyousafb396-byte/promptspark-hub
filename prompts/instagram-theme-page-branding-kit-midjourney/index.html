Instagram Theme Page Branding Kit — Midjourney Prompt

A complete visual identity for an Instagram theme page — profile picture, highlight covers, and post backgrounds in one cohesive style.

AI ToolMidjourney
CategoryImage Prompts
DifficultyIntermediate

📋 Copy the Prompt

Branding kit for an Instagram theme page about [NICHE, e.g. stoic mindset quotes]: 1) a bold minimalist profile picture — a geometric [SYMBOL, e.g. marble bust] icon in gold on a deep charcoal background, perfectly centered, instantly readable at tiny sizes; 2) a set of matching highlight cover icons in the same gold-on-charcoal style, flat vector look; 3) a carousel post background template — dark textured charcoal with a subtle vignette and generous empty center space for quote text, elegant and premium. All pieces share one palette: gold, charcoal, and off-white. Clean professional brand identity, flat vector style, high contrast --ar 1:1 --style raw --v 6.1 --no text errors, watermark, photo, 3d render, clutter, gradients

🚀 How to Use This Prompt

  1. Open Midjourney and paste the prompt with your niche, symbol, and palette.
  2. Generate the profile picture first — test it at 110px to confirm it reads at small size.
  3. Generate highlight covers as a matching set, one icon per highlight topic.
  4. Use the carousel background template for every quote post to build visual consistency.
  5. Export everything at 1080x1080 and apply the kit across the whole profile at once.

💡 Pro Tips

  • One palette across every asset is what makes a theme page look professional instead of random.
  • Test the profile picture in dark mode and light mode — gold on charcoal survives both.
